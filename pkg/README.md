# Public API Package

This directory contains the exported API for users of the go-better-auth library.

## Structure

- `auth/` - Main authentication API
- `config/` - Configuration types and helpers
- `middleware/` - Framework middleware exports
- `types/` - Public types and interfaces

## Responsibilities

- Provide clean, simple API for library users
- Export only necessary types and functions
- Maintain backward compatibility
- Provide framework-agnostic interfaces
