# Infrastructure Layer

This directory contains infrastructure adapters and external service integrations.

## Structure

- `db/` - Database implementations (PostgreSQL, MySQL, etc.)
- `jwt/` - JWT token management
- `mail/` - Email service integrations
- `logger/` - Logging infrastructure
- `config/` - Configuration management

## Responsibilities

- Implement port interfaces defined in core
- Handle external service integrations
- Provide concrete implementations of repositories
